For reviewers: see each state

Each link reloads the page with a setting in the address. No code changes needed.

  • Loading – the list takes 4 seconds to load.
  • Error – the first load fails; “Try again” then succeeds.
  • Empty – clears your saved list, as for a new user.
  • Save error – adding or removing a book fails.
  • Sample books – adds three books to an empty list.
  • Normal – no demo settings.
